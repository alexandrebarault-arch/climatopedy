# Invariants

Le harnais vérifie les propriétés incontestables : valeurs finies, absence d’Infinity/NaN, populations/cohortes non négatives, agrégats cohérents, calories dans `[400,3500]`, déficit dans `[0,100]`, et déterminisme à entrées identiques.

Tw nullable, données absentes, zéros observés et valeurs hors domaine Stull restent distincts. Aucune règle scientifique supplémentaire n’est inventée.
