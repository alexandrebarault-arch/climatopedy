# Golden Master update policy

Un échec suit le processus : modification du modèle → différence numérique → rapport d’impact → revue humaine → approbation → nouvelle version. Aucun échec ne régénère automatiquement V0.

Une mise à jour doit utiliser une commande explicite, être examinée et conserver V0 dans Git. Elle doit documenter les pays, années, scénarios, algorithmes, deltas, valeurs nulles et changements de provenance concernés.
