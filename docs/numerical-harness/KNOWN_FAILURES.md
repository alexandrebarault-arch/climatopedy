# Known failures

Les anciens tests de statut d’habitabilité contiennent une signature positionnelle obsolète et un test de structure attend un ancien texte de composant. Ils sont conservés comme état préexistant et ne sont pas corrigés par le harnais V0.

FAST/FULL isolent les contrôles numériques nouveaux et passent indépendamment de ces défaillances historiques.
