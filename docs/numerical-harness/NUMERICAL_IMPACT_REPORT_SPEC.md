# Numerical Impact Report specification

Le rapport doit contenir : cas Golden testés/unchanged/changed, algorithmes, pays, années, scénarios, médianes et P95 absolus/relatifs, plus grands deltas positifs/négatifs, NaN, Infinity, échecs d’invariants, échecs connus et inattendus. Les changements doivent être identifiables par indicateur, zone, année et scénario.
